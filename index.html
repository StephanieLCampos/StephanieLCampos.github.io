Mimica: Real-Time Voice-Preserving Translation

Senior design project · 4-person team · Jun 2025 to May 2026

A real-time speech-to-speech translation pipeline (ASR, neural machine translation, and voice-cloned text-to-speech) built to keep the speaker's own voice in the translated output.

  • Applied knowledge distillation to the Coqui XTTS v2 speaker encoder, replacing a ResNet teacher with a transformer student (20M to 15M parameters). This cut voice-cloning inference latency 25% while keeping 96% of baseline voice similarity.
  • Profiled each pipeline stage, found voice-cloning synthesis took about 92% of processing time, and benchmarked four configurations on a GPU-backed AWS EC2 instance to choose the final model.
  • Built a web test harness that ran the full pipeline from uploaded source audio to downloadable translated output.

Recipient of SCU's CSEN Award for Technical Excellence (top senior design project)

  • Python
  • PyTorch
  • Coqui XTTS v2
  • AWS EC2

QUIC Congestion-Control Optimization with Q‑Learning

Research Assistant, WIN Lab, Santa Clara University · Aug 2025 to Jun 2026

A reinforcement-learning agent that tunes QUIC and CUBIC congestion-control parameters in real time across video streaming, file transfer, and video conferencing flows that share one bottleneck.

  • Monitored per-connection latency, throughput, and jitter to adjust protocol parameters during live runs.
  • Reduced p95 video frame-completion delay by 113.8 ms and raised video completion rate by 3.22 percentage points against a static RFC-aligned baseline across 20 held-out trials.
  • Improved total receiver goodput while preserving file-transfer throughput.
  • Python
  • Q-learning
  • QUIC
  • Docker

Homey: Roommate-Matching Web App

3-person team · Sep 2025 to Dec 2025

A swipe-based platform that matches individuals and groups for shared housing, with real-time updates for every member.

  • Designed and built a backend REST API with 38 Express endpoints and 9 Mongoose schemas, including a dual-entity feed for individual and group profiles.
  • Designed the group-formation state machine, covering profile suspension, cascading match invalidation across 4 MongoDB collections, audit-trail snapshots, and automatic group teardown.
  • Found and fixed race conditions through concurrent-session testing by adding a server-side guard chain before writes, and added 17 typed Socket.io events that keep clients in sync without polling.
